# Inventory Management System
     A full-stack application built with Angular (frontend) and Node.js + Express (backend) for managing gadget inventory with secure authentication.

# Project Structure
    ├── frontend/   # Angular app
    ├── backend/    # Node.js API

# Features
    Gadget CRUD operations
    Bulk update & bulk delete
    SQLite database


# Setup
# Backend
    cd backend
    npm install
    npm run dev
# Frontend
    cd frontend
    npm install
    ng serve
Backend: http://localhost:3000
Frontend: http://localhost:4200
